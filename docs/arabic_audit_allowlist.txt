# WHY THESE ARE HERE, and why the threshold was NOT lowered instead.
#
# Task 2's generated SFT/DPO data (data/generated/**) is derived from `asas_albalagha`
# ONLY - measured: 394/394 classical chunks, 0/337 dialect chunks - so the generating
# model never saw the rights-pending dialect corpus and cannot have copied from it.
#
# But the generation prompt asks for SAUDI DIALECT phrasing over those classical
# sources (`dialect: Saudi`, questions like "وش يعني"). So the output collides with the
# everyday connectives of a Saudi dialect dictionary constantly and by design. Every
# run below is a generic connective, a lexicographic formula, or a discourse marker.
#
# MEASURED at intake: 116 distinct HELD_ONLY runs, longest FOUR words
# ("لها أكثر من معنى" = "it has more than one meaning", one occurrence in the dialect
# corpus). Nothing at five words or more matched anywhere. A real leak of dictionary
# content would show long runs; this shows the opposite shape.
#
# These are listed individually ON PURPOSE. Raising --min-words to 5 would have
# silenced them in one line, and would ALSO have silenced any genuine five-word leak
# in every future commit, in every file, forever. An allowlist entry suppresses
# exactly one known-safe string and leaves the detector at full sensitivity for
# everything else. That difference is the whole reason the allowlist exists.
#
# قائمة مُصفّاة يدويًا: عبارات عامة قصيرة، لا محتوى مصدريًا فيها.
